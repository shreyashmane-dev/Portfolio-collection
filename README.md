# Portfolio Collection

A curated collection of developer portfolio designs and creative engineering systems for Shreyash Mane.

---

## Directory Overview

- **portfolio-1/**: Production-grade anime-inspired portfolio built with Next.js (App Router), GSAP ScrollTrigger, Lenis smooth scroll, Three.js / React Three Fiber, procedural 3D katana, manga panel layouts, and dual theme engine.
- **portfolio-2-best/**: Advanced Next.js portfolio showcase featuring 3D glTF Swordsman cinematic model (`swordsman.glb`), dynamic lighting shaders, comprehensive project index, and custom interaction suite.
- **portfolio-3/**: Cyber-anime portfolio built with Vite, React 19, Three.js, GSAP, and Tailwind CSS. Features custom Web Audio sound effects, character key visuals, portal modals, and interactive project archives.
- **portfolio-4-beyond-the-code/**: Cyberpunk / Neo-Tokyo portfolio edition titled "Shreyash — Beyond The Code". Built with Vite, React 19, Three.js / Drei, Zustand, and Tailwind CSS. Features interactive rain FX, layered parallax SVG art, audio synthesizer, and tilt cards.

---

## Getting Started

To run any portfolio in this collection, navigate to its respective directory:

### Portfolio 1 (Next.js Anime Creative)

```bash
cd portfolio-1
npm install --legacy-peer-deps
npm run dev
```

### Portfolio 2 Best (Next.js 3D Model Edition)

```bash
cd portfolio-2-best
npm install --legacy-peer-deps
npm run dev
```

### Portfolio 3 (Vite Cyber-Anime Edition)

```bash
cd portfolio-3
npm install
npm run dev
```

### Portfolio 4 (Beyond The Code Edition)

```bash
cd portfolio-4-beyond-the-code
npm install
npm run dev
```
