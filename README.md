# Portfolio Collection

A curated collection of developer portfolio designs and creative engineering systems for Shreyash Mane.

---

## Directory Overview

- **portfolio-1/**: Production-grade anime-inspired portfolio featuring GSAP ScrollTrigger, Lenis smooth scroll, Three.js / React Three Fiber, procedural 3D katana and swordsman finale, manga panel layouts, and dual theme engine.

---

## Getting Started

To run any portfolio in this collection, navigate to its respective directory:

```bash
cd portfolio-1
npm install --legacy-peer-deps
npm run dev
```
